# 🛡️ PhishQuest

PhishQuest is a gamified cybersecurity awareness web application developed for primary school students. The application aims to improve students' awareness of phishing attacks through interactive learning, simulations, quizzes, and rewards.

---

## 📌 Project Objective

To educate students about phishing attacks in an engaging and interactive way while helping them identify suspicious emails, fake websites, and online scams.

---

## 🚀 Features

- User Login
- User Registration
- Dashboard
- Learning Module
- Email Phishing Simulation
- Website Phishing Simulation
- Interactive Quiz
- Reward & XP System
- User Profile
- Teacher Dashboard
- Progress Tracking

---
